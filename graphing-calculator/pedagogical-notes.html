🧮 Graphing Calculator

A calculator, grapher and table of values — self-contained, offline, no ROM

🚀 Launch Applet

🎯 Where This Came From

Built as the calculator drawer for verbatim, the activity page that records a student's conversation with an AI. The three activities there ask students to produce numbers rather than receive them, and until now the page offered no way to work one out.

A TI-84 simulator was the obvious first thought and the wrong one. Emulating one needs Texas Instruments' ROM, which cannot be redistributed; and an emulator would hand back keystrokes, leaving what a student meant to be reconstructed afterwards — the exact problem verbatim exists to avoid. So the shape is familiar and the engine is our own.

⚙️ Design Decisions

  • Degrees and radians live on the face. On a real graphing calculator the mode is two menus down, and it silently changes the answer: sin(30) is 0.5 or -0.988 and both are correct. Activity 1 turns on students noticing that sin θ ≈ θ holds in radians and not in degrees, so the mode is the one setting that is always visible.
  • A table, not only a graph. Activity 1 asks students to find how small an angle has to be by trying values. A column of values is the tool for that; a curve is not. Enter sin(x) - x from 0 by 0.05 and the answer is legible at a glance.
  • Fewer, bigger keys. The activities are meant to be tried on a phone, and there is a real keyboard here — so nothing needs reaching through a 2nd or ALPHA modifier, and a 50-button faceplate would only be in the way.
  • Implicit multiplication reads left to right. 2x, 3(x+1) and 2sin(x) all work, and 1/2x means (1/2)·x. Calculators genuinely disagree here; this one matches how the expression was typed.
  • Errors say something a student can act on. 2 + answers "the expression stops early", not SYNTAX ERROR.

📐 What It Knows

sin cos tan asin acos atan sqrt √ abs ln log exp floor ceil round min max mod, powers with ^, factorial with !, π and e. Powers group to the right, so 2^3^2 is 512; and -2^2 is −4, which is what a textbook means by it.

The graph pane pans by dragging and zooms on the wheel. A curve is broken wherever the function has nothing to say, so tan(x) does not draw a vertical stroke through its asymptote.

🔌 Dropping It Into a Page

The engine is one marked block near the top of the file. It touches no DOM and returns plain numbers, so it lifts out whole. Every use also raises a calc-use event — { kind, expr, result, deg, ts } — which is the seam a page that records a session listens on, so that reaching for a number is recorded rather than inferred.

Self-contained: no external scripts, no fonts, no network. It opens from a folder, or from a file, with nothing beside it.
