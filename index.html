🧩 Applet Library

A collection of interactive web applets for mathematics and science education.

Applets

  • 🏛️ Close Reader
    Read and annotate five different source documents, including Plato's Allegory of the Cave, with translations for many texts in English, Chinese, Hindi, and Spanish. Select any passage, ask a question, and an AI thinking partner responds in the margin — pick any model in the 🤖 AI Setup menu (a local model if you have one running, or a cloud provider with your own key). Notes are saved to your browser; export to JSON for backup or transfer.
  • 🪐 Orbit Explorer
    Explore the dynamics of Collatz-style functions: set the parameters m, b, and d to define a function pair, seed the iteration with a starting value, watch the trajectory and any cycle it falls into, and save interesting cases for comparison. Includes an AI thinking partner — pick any model in the 🤖 AI Setup menu (a local model if you have one running, or a cloud provider with your own key).
  • 🧲 Forces on a Ramp
    Interactive physics simulation for exploring forces on inclined planes. Visualize force decomposition, friction effects, and energy conservation with draggable objects and real-time physics.
  • 🍬 Integer Partitioning
    Explore integer partitions through jelly bean distribution, Ferrers diagrams, and constraint filters.
  • 🎱 Momentum & Collisions
    Interactive billiard ball physics demonstrating conservation of momentum in elastic collisions. Discovery learning through direct manipulation. Companion to Forces on a Ramp - both built from McKenzie Sorce's field observations.
  • 🧭 Reference Angles v2
    Enhanced unit circle with three new features: Predict Signs Mode (purple button - predict +/− for sin/cos/tan before revealing), Exact Values for special angles (0°/30°/45°/60°/90° show fractions/radicals), and All Quadrants view (see reference triangles in all four quadrants simultaneously with color-coded arcs). Built from field-lesson student data.
  • 📐 Pell Explorer
    Explore the mathematics of Pell’s equation and its solutions, inspired by the work of Indian mathematicians. Visualize integer solutions and patterns interactively.
  • 🌳 Tree Diagram Builder
    Build probability tree diagrams interactively. Sandbox mode lets students add and edit branches, with live validation that sibling probabilities sum to 1 and automatic computation of joint probabilities at each leaf. Loads example problems from JSON files (bundled or teacher-authored) at three scaffolding tiers: fully worked, partially completed, and blank.
  • 🪢 Clique
    A Connections-style word puzzle game for the classroom: build, share, and play 4×4 puzzles where players group 16 items into four hidden categories. Puzzles are organized by grade band and content area.

About

These applets are designed for hands-on mathematical exploration in the classroom. Each applet is self-contained with its own README and can be used independently.
