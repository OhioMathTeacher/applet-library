🧩 Applet Library

A collection of interactive web applets for mathematics and science education.

Applets

  • 🏛️ Marginalia
    A reading-and-writing studio. Read and annotate five source documents — Plato's Allegory of the Cave, Gandhi, Confucius, Bryant, and Ibsen — with the interface in six languages (English, Spanish, Chinese, Hindi, Greek, Norwegian) and several readings offered in translation. Select any passage to think in the margin: freewrite privately in the spirit of Peter Elbow (auto-saved, never graded), send passages to a dated Writer's Journal, and call on two AI thinking partners — Socrates, who questions, and Elbow, who encourages (named for Peter Elbow's believing game). Pick any model in the 🤖 AI Setup menu — a local model if you have one running, or a cloud provider with your own key. Everything saves to your browser; export to JSON for backup or transfer.
  • 🪢 Clique
    A Connections-style word puzzle game for the classroom: build, share, and play 4×4 puzzles where players group 16 items into four hidden categories. Puzzles are organized by grade band and content area.
  • 🪐 Orbit Explorer
    Explore the dynamics of Collatz-style functions: set the parameters m, b, and d to define a function pair, seed the iteration with a starting value, watch the trajectory and any cycle it falls into, and save interesting cases for comparison. Includes an AI thinking partner — pick any model in the 🤖 AI Setup menu (a local model if you have one running, or a cloud provider with your own key).
  • 📜 Teleprompter
    A single-file browser teleprompter for recording short video lessons and podcasts. Load a script from a .txt file or paste it directly, adjust scroll speed and font size live, pick a reading theme (amber, green, white, black, paper), save multiple scripts for reuse. Works offline; no account, no server. Great as an OBS Browser Source — drop the URL into OBS and the teleprompter scrolls inside your recording scene.
  • 🍬 Integer Partitioning
    Explore integer partitions through jelly bean distribution, Ferrers diagrams, and constraint filters.
  • 🌳 Tree Diagram Builder
    Build probability tree diagrams interactively. Sandbox mode lets students add and edit branches, with live validation that sibling probabilities sum to 1 and automatic computation of joint probabilities at each leaf. Loads example problems from JSON files (bundled or teacher-authored) at three scaffolding tiers: fully worked, partially completed, and blank.
  • 🗂️ Sort Lab
    An open-sort surface for talking about how learners categorize. Students drag items into groups they invent themselves, then name the rule behind each group. Six sets ship with it — Triangles, Shapes, Letters, Characters, Foods, and People — and any item can be turned or flipped, so a class can test whether orientation belongs in the rule. The interface runs in English, Spanish, and Chinese.
  • 🧠 Watch Your Own Thinking
    Three metacognitive math puzzles that record how you solve — then hand the reasoning back to you.
    • Metadoku (Calcudoku) — fill the grid so every cage hits its target. What it makes visible is constraint deduction: which clue forced which cell, and how you know the answer is the only one.
    • Metaplete (delete-to-target) — remove cells until each row and column hits its target, by sum or product. What it makes visible is hypothesis-testing: when you knew, when you guessed, and when you backed a choice out.
    • Metagons (arithmagons) — each edge carries the sum of the two circles it joins, and the circles are hidden, so you work backward. What it makes visible is inverse reasoning: where you entered the system and how you unwound it.
    All three run the same three steps. Infer the rules from a worked example, then solve, with every move quietly time-stamped. Scrub back through your own solve and attach notes at the moments that carried real reasoning. Then generate an editable, downloadable “thinking analysis” — your strategy, in your words. No data leaves the device. Reasoning made visible, not drill in a nicer costume.

About

These applets are designed for hands-on mathematical exploration in the classroom. Each applet is self-contained with its own README and can be used independently.
