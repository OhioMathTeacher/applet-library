An unsolved problem

Pick a whole number and apply the rule to the right, over and over. Watch where your number goes.

Where does every starting number end up? Nobody has proved it.

Whatever you notice today is real mathematical evidence, not a rediscovery of something in the back of a book.

The rule

If n is even: n ÷ 2

If n is odd: 3n − 1

Orbit Explorer starts on this rule. Its sliders set m, b, and d in: odd → m·n + b, even → n ÷ d. Today's rule is m = 3, b = −1, d = 2.
