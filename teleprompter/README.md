# Teleprompter

A single-file browser teleprompter for recording short video lessons,
demos, and podcasts. No install, no account, no cloud — runs entirely
in your browser.

**Live**: https://ohiomathteacher.github.io/applet-library/teleprompter/

## Features

- **Load a script** from a `.txt` or `.md` file, or paste it directly
- **Adjustable scroll speed** (live, while scrolling)
- **Font size** 8–200px — make text as small or as big as you need
- **Five color themes** — Amber on black, Green on black, White on
  black, Black on white, Black on paper
- **Save multiple scripts** to your browser; reload any saved script
  later
- **Mirror flip** for hardware teleprompter rigs (text reflected off a
  glass)
- **Keyboard shortcuts** in prompter mode:
  - `Space` — play/pause
  - `↑` / `↓` — nudge scroll position
  - `+` / `−` — adjust font size
  - `F` — fullscreen
  - `Esc` — back to editor

## Recommended OBS workflow

Drop the teleprompter into OBS as a Browser Source pointing at the
URL above. The teleprompter scrolls inside your OBS recording scene
— no second monitor needed, no toggling between windows. Use the
keyboard shortcuts to control playback during a take.
