# Vanishing Point

Five beams, one horizon. A retro shooter for an NES-style controller.

## How to play

Five beams run off to a single vanishing point on the horizon. Hop between them, shoot fifteen white saucers to clear each sector, then try to torpedo the sector ship as it crosses the far end of the field.

| Button | Keyboard | Does |
|---|---|---|
| D-pad | Arrows | Hop from beam to beam. |
| A | Z or K | Laser. |
| B | X or J | Torpedo: three per sector. Torpedoes destroy anything; lasers bounce off some things. |
| Select | Shift | Side view: the same scene seen from the side, showing how the picture is drawn in perspective. |
| Start | Enter | Play / pause. |

M mutes the sound. A standard USB gamepad works too.

Later sectors bring new things down the beams: yellow chirpers are a bonus, sparks are to dodge, and green blockers can only be torpedoed or avoided.
