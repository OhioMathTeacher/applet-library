A roster you can show anybody

Fifteen public-domain portraits — writers, scientists and reformers — for Name Game. The app already arrives with the fifteen most recent presidents; this is a second roster, for when you want different faces. Neither one is anybody’s student, which is the point.

Name Game reads a person’s name out of the filename, so a roster is just a folder of pictures. This one is named the way the app expects — First_Last_Demo_Portraits.jpg — so it works the moment you unzip it and point the app at the folder. Nothing is uploaded and no account is involved, here or in the app.

Every portrait was checked against Wikimedia Commons licence metadata and kept only if it came back public domain. One was dropped for failing that test: the lead portrait of Srinivasa Ramanujan is CC BY 4.0, not public domain. Each is re-encoded as a plain RGB baseline JPEG, no larger than 800px, so the app has nothing unusual to open.

Download the roster (zip)

Unzip it, then in Name Game use File → open a photo folder and choose name-game-roster.
